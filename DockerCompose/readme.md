# Учебные проекты по Docker и Docker Compose

Этот репозиторий содержит коллекцию практических проектов и лабораторных работ, развернутых с помощью **Docker Compose**. Каждый проект представляет собой изолированную среду для изучения контейнеризации, настройки баз данных, работы с веб-интерфейсами и управления переменными окружения.

---

## 📂 Структура репозитория и список проектов

В репозитории представлены следующие реализованные проекты:

1. **Joomla** — развертывание популярной системы управления контентом (CMS) с постоянным хранением данных.
2. **WordPress** — классический веб-стек для создания сайтов и блогов в изолированных контейнерах.
3. **MySQL + phpMyAdmin** — связка реляционной базы данных MySQL с удобной веб-панелью администрирования.
4. **PostgreSQL** — развертывание СУБД с поддержкой кастомных скриптов первичной инициализации (`init.sql`).
5. **PostgreSQL + pgAdmin** — продвинутая СУБД в комплекте с мощным инструментом графического управления.
6. **drawDB** — современный инструмент для визуального проектирования баз данных и генерации схем.
7. **LibreDB Studio** — легковесная веб-IDE для работы с базами данных с использованием конфигурации через переменные окружения (`.env`).
8. **HomeHub** — универсальный семейный дашборд (заметки, трекеры, списки) с кастомным маппингом портов и гибкой настройкой.
9. **CloudBeaver** — веб-версия популярного инструмента DBeaver для удаленного администрирования баз данных прямо из браузера.

---

## ⚙️ Системные требования

Для запуска любого из проектов в вашем окружении должны быть установлены:
* **Docker** (с поддержкой Docker Compose v2)
* Терминал (bash/zsh)
* Современный веб-браузер

---

## 🚀 Как работать с проектами

Каждый проект находится в собственной директории и полностью независим от остальных.

1. Перейдите в папку интересующего вас проекта:
   ```bash
   папка_проекта

```

2. Запустите сервисы в фоновом режиме:
```bash
docker compose up -d

```


3. После завершения работы вы можете корректно остановить проект и очистить ресурсы (включая тома данных и образы):
```bash
docker compose down --rmi all -v

```
