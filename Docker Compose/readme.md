# Отчет по практической работе: Синхронизация Git и запуск Docker Compose

## 1. Синхронизация форка с репозиторием преподавателя (Upstream)
Для получения новых учебных материалов из главного репозитория были выполнены следующие команды:

1. Скачивание новых изменений из оригинального репозитория:
   ```bash
   git fetch upstream

```

2. Слияние изменений с локальной веткой:
```bash
git merge upstream/master

```


3. Отправка обновленных данных в свой удаленный репозиторий на GitHub:
```bash
git push origin master

```


## 2. Развертывание CMS Joomla и базы данных MariaDB через Docker Compose

В рамках задания был развернут многоконтейнерный проект с использованием `compose.yaml`.

### Подготовка окружения

Создана директория для проекта и пустой конфигурационный файл:

```bash
mkdir -p joomla-docker && touch joomla-docker/compose.yaml && cd joomla-docker

```

Далее файл был открыт в консольном редакторе `nano` и заполнен конфигурацией (сервисы `db` на базе MariaDB и `joomla`):

```bash
nano compose.yaml

```


![Код конфигурации в терминале](Docker Compose/git-sync.png)

### Запуск контейнеров

Проект запущен в фоновом режиме:

```bash
docker compose up -d

```


*![](Docker Compose/Pulled_and_Started.png)*

## 3. Настройка Joomla и решение проблемы с подключением

После запуска контейнеров веб-установщик был открыт по адресу `http://localhost:8082`.

**Важный момент при настройке базы данных:**
По умолчанию Joomla пытается подключиться к БД по адресу `localhost`. Так как база данных находится в изолированном контейнере Docker, адрес хоста был изменен на имя сервиса в Docker-сети — **`db`**.


*![](Docker Compose/joomla-db.png)*

После успешной установки и удаления папки `installation` сайт стал доступен для работы.


*![](Docker Compose/joomla-sait.png)*
