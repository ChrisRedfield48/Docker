## 🚀 Как работать с проектами

Каждый проект находится в собственной директории и полностью независим от остальных.

**1. Перейдите в папку интересующего вас проекта:**
```bash
cd папка_проекта
```

**2. Запустите сервисы в фоновом режиме:**
```bash
docker compose up -d
```

**3. После завершения работы остановите проект и очистите ресурсы** (включая тома данных и образы):
```bash
docker compose down --rmi all -v
```

> ⚠️ Флаг `-v` удаляет именованные тома, объявленные в compose-файле — используйте его, если хотите полностью чистый старт, но пропустите, если нужно сохранить данные между запусками.
